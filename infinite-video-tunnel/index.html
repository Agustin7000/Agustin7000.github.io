¿Video transparente exportado desde Filmora? La versión web puede no abrir CineForm y la grabación del navegador no garantiza alfa. El programa de Windows v1.2 ya cuenta con vista previa por fotogramas usando FFmpeg. Descargá el ZIP desde GitHub, ejecutá INICIAR_WINDOWS.bat y seleccioná «Conservar transparencia» para exportar MOV ProRes 4444.

El archivo original nunca se envía a un servidor. En Firefox normalmente se exporta WebM; para MP4 garantizado, usá el renderizador local incluido en el repositorio.
