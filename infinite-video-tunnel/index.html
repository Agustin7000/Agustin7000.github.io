¿Video transparente exportado desde Filmora? La versión web no puede reproducir directamente muchos MP4 CineForm de Filmora. La app Windows v2.1 ofrece reproducción continua (▶ Play/Pausa) del túnel con transparencia usando FFmpeg, sin convertir el original. La grabación del navegador no garantiza alfa. Descargá el ZIP desde GitHub, ejecutá INICIAR_WINDOWS.bat y seleccioná «Conservar transparencia» para exportar MOV ProRes 4444.

El archivo original nunca se envía a un servidor. En Firefox normalmente se exporta WebM; para MP4 garantizado, usá el renderizador local incluido en el repositorio.
